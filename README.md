# transitlog-apc-sink [![CI/CD](https://github.com/HSLdevcom/transitlog-apc-sink/actions/workflows/ci-cd.yml/badge.svg)](https://github.com/HSLdevcom/transitlog-apc-sink/actions/workflows/ci-cd.yml)

Sink for writing APC (passenger count) data to Transitlog DB. This project is part of Transitlog project.

## Building

### Dependencies

- [transitdata-common](https://github.com/HSLdevcom/transitdata-common)
